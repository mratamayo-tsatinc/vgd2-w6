Sections

Each section has its own answer key and grading rules. Tick which attributes count toward a student's score for that section — Name is an exact filename match, Ext is the detected-byte extension, W/H are width/height, AR is aspect ratio, Orient is orientation. Leave Points blank for auto-derived scoring (items × attributes checked), or set a number to scale that section to a fixed point total. Pick the radio button on a row to select that section — its answer key (built via "Upload Model Answers" below) and the table beneath both follow whichever section is selected. Remember to Save Sections after any change.
Software Check is a separate, unscored gate — turn it on and name a program (e.g. "Adobe Photoshop") to require that a file's own metadata mentions it; a file that fails this check is rejected outright, but the check itself never adds or removes points. Not available on MANIFEST sections (no real file to inspect).

General Settings
Allowed pixel difference between a submitted file's width/height and the values recorded in that section's answer key, for any section with the Width/Height checks enabled. A resize that should be exact keeps this at 0 (the recommended default). Applies activity-wide — not applied to PDF files, see the note below.
PDF submissions are verified by file signature + base name + slot-lock only. A PDF's page size is in points, tied to export DPI, and doesn't map 1:1 to a raster image's pixel dimensions, so the width/height/aspect-ratio checks are intentionally skipped for PDF files even in sections that have them enabled.
Perceptual Hash Scoring
Max Hamming Distance between a submission's perceptual hash and the answer key's hash that's still eligible for any credit on the Perceptual Hash attribute. Used directly as the zero-credit cutoff in Linear mode below; Tier mode uses its own breakpoints instead and ignores this value. Always skipped for PDF files — see the PDF note above.
Linear: score = 1 − (distance ÷ threshold), clamped to [0, 1]. Tier: the first breakpoint below (sorted by Max Distance) whose Max Distance is ≥ the submission's actual distance sets the score.
Max DistanceScore (0–1)
Rows don't need to be entered in order — they're sorted by Max Distance automatically when saved. If a submission's distance exceeds every row here, it gets 0 credit for the Perceptual Hash attribute on that file.
